# Contributing

A useful change improves a real reference-to-game decision, a reproducible tool, or a demonstrated failure. Include the smallest case that reproduces the issue, expected behavior, actual behavior and the relevant evidence. Use synthetic or authorized fixtures without credentials or private prompts.

Keep new input adapters optional and preserve raw files. New generation providers must record durable intent, avoid blind retries after ambiguous outcomes, preserve credential boundaries and have offline tests. New runtime helpers need behavior tests, not just snapshots of their implementation.

Run the checks in [AGENTS.md](AGENTS.md). Discuss engine-specific additions as profiles instead of changing the neutral contract. Case studies should include both what matched and what remains different.
