# Credits and sources

Created by [gokayfem](https://github.com/gokayfem). This repository develops the reference-driven game workflow used for Jungle Jetboat Jump, Jellyworks, Petal Pals and Sunshine Train Battle. Those game implementations and their asset pipelines were developed with Claude Code using the supplied image, sheet and video references. The reusable toolkit was assembled and tested afterward; the cases are not a controlled evaluation of this packaged skill.

Related projects informed the packaging and evidence-oriented approach:

- [video-to-blender](https://github.com/gokayfem/video-to-blender)
- [shader-skills](https://github.com/gokayfem/shader-skills)
- [video-to-physics](https://github.com/gokayfem/video-to-physics)
- [video-to-css](https://github.com/gokayfem/video-to-css)

Technical references: [Three.js](https://threejs.org/docs/), [Vite](https://vite.dev/guide/), [glTF](https://github.com/KhronosGroup/glTF), [fal queue API](https://fal.ai/docs/api-reference/inference-api/queue/submit), [Claude plugin manifests](https://code.claude.com/docs/en/plugins-reference), [Agent Skills](https://agentskills.io/).
